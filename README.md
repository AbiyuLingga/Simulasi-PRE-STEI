# Simulasi-PRE-STEI

Simulator Praktikum Rangkaian Elektrik (EL-2101) STEI ITB berbasis Web 3D (React, Three.js / React Three Fiber, Zustand, dan solver MNA).

## Fitur Utama
- **Instrumen 3D Interaktif**: Osiloskop Rigol DS1052E, Generator Sinyal DG1012, Multimeter Digital DM3058, Dual DC Power Supply, Kotak Dekade Resistor 8-Skala, Kit Praktikum LDTE (#14, #5, #22, RL & RC), dan Breadboard 830-hole (2D & 3D).
- **Kabel Adaptif 3D**: BNC-BNC, BNC-Banana, BNC-Buaya, Banana 4mm tumpuk, serta penghindar kolisi kabel & Y-splitter.
- **34 Sub-Percobaan EL-2101 (Modul 1–5)**: Panduan wiring interaktif, pengaturan instrumen, dan tabel lembar kerja (BCL).

## Menjalankan Secara Lokal
```bash
pnpm install
pnpm dev
```

## Pengujian & Build
```bash
pnpm test
pnpm build
```
